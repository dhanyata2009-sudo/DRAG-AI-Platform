# DRAG_AI
Diploma Final Year project 


### PPT image generation
PPT illustrations use Hugging Face HF Inference with `stabilityai/stable-diffusion-3-medium-diffusers`.
Older `.env` values such as `black-forest-labs/FLUX.1-schnell` are automatically migrated to the supported image model.
Set `HF_TOKEN` to a Hugging Face token with Inference Providers access.
